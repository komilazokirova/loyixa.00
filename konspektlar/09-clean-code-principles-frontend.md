# 🧼 Frontend Dasturlashda Clean Code Qoidalari

Toza kod yozish — nafaqat jamoada ishlashni osonlashtiradi, balki loyihani kelajakda kengaytirishda xatoliklarning oldini oladi.

---

## 🎯 4 ta Oltin Qoida:

1. **DRY (Don't Repeat Yourself)**:
   * Bir xil kodni ikki joyda takrorlamang. Uni alohida funksiya yoki Custom Hook'ga chiqaring.
2. **KISS (Keep It Simple, Stupid)**:
   * Oddiy yechim har doim murakkab arxitekturadan yaxshiroq.
3. **Single Responsibility (Yagona javobgarlik)**:
   * Bitta komponent faqat bitta ishni bajarsin (masalan, `UserCard` faqat profilni ko'rsatsin, API'dan yuklash bilan shug'ullanmasin).
4. **Aniq va ma'noli nomlash**:
   * O'zgaruvchilarga `data`, `item`, `x` emas, nima ekanligini bildiruvchi aniq nom bering (`userData`, `productItem`).
