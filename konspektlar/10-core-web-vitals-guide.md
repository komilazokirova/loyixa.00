# 🚀 Core Web Vitals: Sayt tezligini oshirish bo'yicha qo'llanma

Google tomonidan veb-sayt foydalanuvchi tajribasini (UX) baholash uchun belgilangan 3 ta asosiy metrika:

---

1. **LCP (Largest Contentful Paint)**:
   * Asosiy katta kontent (masalan: hero rasm yoki katta matn) qanchalik tez ko'rinishi.
   * *Yaxshi ko'rsatkich*: < 2.5 soniya.
2. **INP (Interaction to Next Paint)**:
   * Foydalanuvchi sahifada biror tugmani bosganda ekranning javob qaytarish tezligi.
   * *Yaxshi ko'rsatkich*: < 200 ms.
3. **CLS (Cumulative Layout Shift)**:
   * Sahifa yuklanayotganda elementlarning kutilmaganda sakrab, joyini o'zgartirishi.
   * *Yaxshi ko'rsatkich*: < 0.1.
