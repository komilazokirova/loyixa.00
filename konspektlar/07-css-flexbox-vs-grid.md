# 🎨 CSS Flexbox vs CSS Grid

Zamonaviy veb-dizaynda qachon Flexbox va qachon Grid ishlatish kerakligi eng ko'p so'raladigan savollardan biridir.

---

## 📌 Asosiy farq:

* **Flexbox (1D - Bir o'lchovli)**: Elementlarni faqat bitta yo'nalishda — yoki qator (row) yoki ustun (column) bo'yicha joylashtiradi.
  * *Eng yaxshi holatlar*: Navbar menyulari, tugmalar guruhi, card ichidagi elementlar.
* **Grid (2D - Ikki o'lchovli)**: Elementlarni bir vaqtning o'zida ham qator, ham ustun bo'yicha kataklarga ajratib joylashtiradi.
  * *Eng yaxshi holatlar*: Butun sahifa tartibi (Dashboard layout), galereyalar, murakkab kartalar to'plami.
